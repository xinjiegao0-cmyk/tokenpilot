# Provider evidence

The Kimi K2.6 capability fixture follows the [official Chinese guide](https://platform.kimi.com/docs/guide/kimi-k2-6-quickstart),
checked 2026-09-16: `max_tokens`, one completion, omitted temperature and seed,
default thinking mode. It does not override thinking or implement tool calls.
The framing allowance of 256 is a conservative local assumption, not a published
provider guarantee. Token-bounded sanity limits are not dollar-spend guarantees.

The [official pricing page](https://platform.kimi.com/docs/pricing/chat) retrieved
on that date describes billing units but did not expose a numeric tariff in the
retrieved content. No numeric Moonshot price fixture has been invented or borrowed
from another region. The configured endpoint is the Chinese API; international
USD tariffs must not silently be substituted. An explicit dated USD price profile
(or a future explicit currency/FX model) is required for cost comparisons.
